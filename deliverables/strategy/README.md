# Strategy docs — read the warning first

This folder holds the project's early strategy writing. **It is historical.**

`DESIGN.md` and `PRODUCT.md` here are byte-identical copies of the two files at the
repo root, and both still describe the sponsor-funded, "free to play" model with
sponsor tiers and a Four Numbers scoreboard. That model was dropped in commits
`acaf3b8` and `4923b00`. **The live code is the specification, not these files.**

For how the project actually works — layout, configuration, the backend, the
access model, conventions — see the **[README at the repo root](../../README.md)**.
That is the only copy kept current; this file used to be a duplicate of it and had
gone stale.
